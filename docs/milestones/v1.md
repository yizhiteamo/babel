## Outstanding

Three validation items remain unchecked, with the reason for each:

- **Supported reading apps translate without OCR** — the pipeline was verified
  end to end on device (English UI translated into Chinese in place), but not
  against a third-party reading app: the emulator has none installed. Note that
  settings-style apps call `setHideOverlayWindows(true)`, so Android hides every
  overlay over them; that is a platform anti-tapjacking measure, not a defect.
- **Sensitive input is excluded** — covered by unit tests over `isProtected` and
  the masked/long-digit rules, but no password field was exercised on device.
- **Ordinary reading workloads remain responsive** — no systematic measurement
  was taken. Scroll behaviour looked correct (6 swipes produced 5 scans and no
  redundant provider calls) but that is not a latency measurement.

Also unverified on device: touch passthrough. It rests on
`FLAG_NOT_TOUCHABLE`, whose semantics are guaranteed by the platform, but the
UI automation needed to confirm it proved unreliable on this emulator.
