# ADR 002 — Phase Scope Lives in Feature Documents

## Status
Accepted

## Decision
Version-specific scope, non-goals, and acceptance criteria live under `docs/features/` rather than in `CLAUDE.md`.

Detailed progress lives in GitHub Issues (amended by ADR 012; it used to be `docs/milestones/`).

## Reason
This keeps project-wide agent instructions stable while allowing product phases to evolve independently.
