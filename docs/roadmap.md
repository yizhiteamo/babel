## Status Meanings

- `Planned`: not yet the active implementation phase
- `Active`: currently being implemented
- `Validation`: implementation largely complete, acceptance testing in progress
- `Complete`: acceptance criteria satisfied
- `Paused`: intentionally not progressing

Only version-level state belongs here.
